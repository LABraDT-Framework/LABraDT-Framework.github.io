Digital Twins. Built to Reuse.

LABraDT is an open-source framework for developing modular, AAS-based Digital Twin applications. It provides reusable software components and abstracts the connectivity to cyber-physical production systems. This enables applications and services to be developed independently of specific production system integrations and tested in a controlled environment. The framework supports the development, testing and validation of Digital Twin and AI-based services before deployment to real product.
